# opnsense Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship public `stalane/opnsense` (agent + 6 skills + site) live on `opnsense.stalane.com` with an apex card.

**Architecture:** Single repo, static root deployed to Pages; agent/skills are markdown only, no build step.

**Tech Stack:** Markdown (agent/skills), single-file HTML site, `wrangler pages deploy`, `gh`, `cfswitch`, `bsk` screenshots.

## Global Constraints

- OPNsense-only hard rule; API-first; retrieval-first against docs.opnsense.org.
- No credentials in repo (host/key/secret per command via env).
- Pages production deploys use `--branch main`.
- Apex card copies `<section class="panel">` verbatim; shot at 1280px via `bsk`.
